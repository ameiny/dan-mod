# Dan Mod

A Minecraft 26.3 mod, adding the GOAT Dan Daniel Mc D.

Happy Birthday Daniel 👾

**Installation Guide:**
1. Install Minecraft Java 26.3+
2. Install the Mod Loader [Fabric](https://fabricmc.net/use/installer/) for the same Minecraft version
3. Download the Mod [Fabric API](https://modrinth.com/mod/fabric-api/versions?c=release&g=26.3)
4. Download the Mod [Geckolib](https://modrinth.com/mod/geckolib/versions?c=release&g=26.3&l=fabric)
5. Download the Dan Mod and put all Mods in %appdata%/.minecraft/mods
6. Start Minecraft, choose the new Fabric Version and gaming can begin!
