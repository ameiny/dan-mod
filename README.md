# Dan Mod

A Minecraft 26.3 mod, adding the GOAT Dan Daniel Mc D.

**Installation Guide:**
1. Install Minecraft Java 26.3+
2. Install the Mod Loader Fabric for the same Minecraft version
3. Download the Mod Fabric API
4. Download the Mod Geckolib
5. Download the Dan Mod and put all Mods in %appdata%/.minecraft/mods
6. Start Minecraft, choose the new Fabric Version and gaming can begin!
